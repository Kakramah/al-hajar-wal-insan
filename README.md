# اسم المشروع

قالب خاص لبدء **موقع عربي صغير ومستقل**. غيّر اسم المشروع ووصفه في هذا الملف وفي `index.html` قبل النشر.

## الحالة

قالب. عند إنشاء مشروع منه، سجّل حالته: جارٍ، منشور، مرجع، أو تجربة.

## التشغيل والتحقق

- المعاينة محلياً: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.
- فحص البنية: `python3 scripts/check.py`.
- بوابة التسليم: `bash ~/khaldoun-projects/khaldoun-web-starter/scripts/بوابة-الويب.sh` من جذر المشروع.
- النشر: حدّد طريقة النشر ورابطه في هذا الملف بعد إعدادها. لا تفترض أن GitHub Pages مفعّل.

## قبل البدء

1. حدّث `AGENTS.md` بحقائق المشروع الفعلية وملفاته وأصوله.
2. استبدل محتوى المثال في `index.html` و`styles.css`.
3. حدّد مصدر الصور والنصوص وحقوق استخدامها، ولا تضع أسراراً أو بيانات خاصة في مستودع عام.
4. نفّذ الفحص والمعاينة، ثم اعمل عبر فرع وPull Request.

قواعد الويب وبوابتها وبنك الأساليب نسختها الوحيدة في `docs/` و`scripts/` هنا، وتُحذف من أي مشروع يُنشأ من القالب (راجع `AGENTS.md`). وهوية خلدون وقيمه في بيته الخاص `~/khaldoun` ولا تُنسخ إلى أي مستودع.

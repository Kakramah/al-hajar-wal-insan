# مواصفة الأسلوب 02: صورة سينمائية بملء الشاشة وذهبي (`02-cinematic-photo-gold`)

> **المالك:** `$STARTER/docs/سجل-الهوية.md` §بنك الأساليب (القاعدة 3.4.2 في `docs/قواعد-الويب.md`).  
> **الموقع المرجعي:** `fi-mithl-hatha-alyawm` (في مثل هذا اليوم).  
> **المصدر المقيس:** `style.css` للموقع المنشور، منقول كما هو في 2026-09-28. أي قيمة هنا تخالفه تُصحَّح منه.

---

## 1 · البصمة

| الحقل | القيمة |
|---|---|
| **الأرضية** | صورة داكنة تملأ الشاشة، فوق أسود `#000000` وكحلي `#062538` |
| **أسرة لون البطل** | ذهبي `#C9A557` |
| **العائلة الخطية** | عناوين Cairo / متن Tajawal (كما في الموقع المرجعي) |
| **الشبكة** | تحريرية غير متناظرة، والعنوان على الجانب فوق الصورة |
| **الملمس والآلية** | ملمس الصورة نفسها، والداكن مشتق من صور منخفضة الإضاءة لا مفروض عليها |

---

## 2 · لوحة التوكنات (:root)

```css
:root {
  --gold: #C9A557;
  --gold-bright: #e8c96a;
  --gold-dim: rgba(201,165,87,0.18);
  --gold-glow: rgba(201,165,87,0.08);
  --ink: #000000;
  --navy: #062538;
  --glass-bg: rgba(6,37,56,0.55);
  --glass-border: rgba(201,165,87,0.15);
  --text-primary: #E8DCC4;
  --text-muted: rgba(232,220,196,0.55);
  --section-pad: clamp(5rem, 10vw, 9rem);
  --inner-max: 1200px;
  --radius: 12px;
}
```

## 2ب · الخطوط (منقولة من الموقع المرجعي)

الموقع المرجعي لا يعرّف الخطوط متغيرات في `:root`، بل يسمّيها مباشرة. هذه قواعده كما هي، مختصرة إلى سطر الخط:

```css
body          { font-family: 'Tajawal', sans-serif; }
.hero-title   { font-family: 'Cairo', sans-serif; }
.section-heading { font-family: 'Cairo', sans-serif; }
.chapter-title   { font-family: 'Cairo', sans-serif; }
```

والأوزان المستعملة 400 و700.

# مواصفة الأسلوب 04: سماوي استخباري (`04-cyan-intel`)

> **المالك:** `$STARTER/docs/سجل-الهوية.md` §بنك الأساليب (القاعدة 3.4.2 في `docs/قواعد-الويب.md`).  
> **الموقع المرجعي:** `the-counter-strike` (الضربة المعاكسة). أول مواقع الأسلوب في السجل هو الجندي والملك، ولم يوجد له مستودع منشور في حساب Kakramah، فالمرجع المقيس هو الموقع الثاني.  
> **المصدر المقيس:** `style.css` للموقع المنشور، منقول كما هو في 2026-09-28. أي قيمة هنا تخالفه تُصحَّح منه.

---

## 1 · البصمة

| الحقل | القيمة |
|---|---|
| **الأرضية** | أسود مخضرّ ليلي `#07140f` |
| **أسرة لون البطل** | سماوي `#00ffff`، ومعه ذهبي `#A8842F` لكنة ثانية |
| **العائلة الخطية** | عناوين Cairo / متن Tajawal (كما في الموقع المرجعي) |
| **الشبكة** | نص جانبي على صورة معتمة (من صف الأسلوب في السجل) |
| **الملمس والآلية** | شاشة وتقنية، ووسوم استخبارية بخط أحادي المسافة (`.intel-tag`) |

**فرقان عن صف السجل:** السجل يذكر سماوي `#00E5FF` وخط هوية مخصص، وهما مأخوذان من المصغّرة. والمقيس في الموقع المرجعي سماوي `#00ffff` وخطا Cairo وTajawal.

---

## 2 · لوحة التوكنات (:root)

```css
:root {
    --bg-dark: #07140f; /* Deep intelligence green/black */
    --text-primary: #e6e6e6; /* Bone white */
    --text-muted: #8b9992;
    --accent-blue: #00ffff; /* Toxic cyan (for the seed) */
    --accent-gold: #A8842F; /* Jableh standard accent */
    --border-color: rgba(230, 230, 230, 0.1);
}
```

## 2ب · الخطوط (منقولة من الموقع المرجعي)

الموقع لا يعرّف الخطوط متغيرات في `:root`، بل يسمّيها مباشرة. هذه قواعده كما هي، مختصرة إلى سطر الخط:

```css
body              { font-family: 'Tajawal', sans-serif; }
h1, h2, h3, .logo { font-family: 'Cairo', sans-serif; }
.intel-tag        { font-family: monospace; }
```
